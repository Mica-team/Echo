# Echo Android v2

This branch is a clean rebuild of the Android app while preserving the existing Google login/authentication setup.

## Goals
- Modern Jetpack Compose foundation
- Dark/light theme
- Real Echo Bluetooth Classic/SPP connection
- Clear command protocol
- Device status and telemetry
- OTA update integration later
- Keep Google login/authentication intact

## Scope
Only the Android app repository is changed by this rebuild. The Echo firmware and website repositories remain separate.
